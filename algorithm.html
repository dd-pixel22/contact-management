1. Insert

  1. If the tree is empty, make the new node the root.
  2. If new ID < current ID, go left; if greater, go right.
  3. If IDs are equal, show "ID already exists" and stop.
  4. Place the new node at the empty spot reached.

2. Search

  1. Start at the root.
  2. If the ID matches, return the node.
  3. If ID < current, go left; otherwise go right.
  4. If NULL is reached, print "Contact not found".

3. Delete

  1. Search for the node by ID.
  2. No child: free it and return NULL.
  3. One child: replace it with that child.
  4. Two children: copy the inorder successor (smallest in the right subtree) into it, then delete the successor.

4. Display (Inorder)

  1. Visit the left subtree.
  2. Print the current contact.
  3. Visit the right subtree.
  4. The result is in ascending order of ID.
